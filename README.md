# Central Ascensão Lunar

Primeira versão simples da central administrativa do Ascensão Lunar.

## O que tem

- Login com Firebase Authentication
- Cadastro de membros pela ficha colada
- Cards de membros
- Adicionar e retirar pontos
- Histórico de pontuação
- Ranking quinzenal por período
- Atividades com controle de entrega e vencedor
- Cadastro de textos enviados pelos membros

## Arquivos

- `index.html`
- `css/styles.css`
- `js/firebase.js`
- `js/app.js`
- `firestore.rules`

## Configuração rápida

1. Crie um projeto no Firebase.
2. Ative Authentication com e-mail/senha.
3. Crie um usuário administrador.
4. Ative Cloud Firestore.
5. Copie os dados do app Web do Firebase.
6. Cole os dados no arquivo `js/firebase.js`.
7. Publique as regras do arquivo `firestore.rules` no Firestore Rules.
8. Envie os arquivos para um repositório no GitHub.
9. Importe o repositório na Vercel.

## Observação

Esta é uma versão inicial, direta e administrativa. Não usa React, Node, build, terminal ou comandos.
